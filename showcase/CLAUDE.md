# Showcase notes for Claude

This folder builds the EchoLight showcase page (Squarespace embed, English and Arabic). To add or change content, read `CONTENT.md` first and use `build/add_content.py` then `build/release.py`. `site/data/events.json` is the single source of truth. Keep service tags honest (see CONTENT.md), keep the owner's wording, and never drop files silently. The owner is cost-conscious: avoid long image reviews; use contact sheets, not one image per file.
