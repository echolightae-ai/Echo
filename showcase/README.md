# EchoLight showcase

`site/` is a self-contained static website (no build step, no server needed). Open `site/index.html` directly, or upload the
`site/` folder to any host (e.g. as `echolight.ae/showcase`).

- `?q=` deep links: `index.html?q=corporate` opens the page pre-filtered, handy for sending a client a tailored link.
- `site/assets/` holds web-sized copies (photos 1280px, videos 5s clips). Originals are not in the repo.
- `site/data/items.js` is generated by `build/build_assets.py` from `curation.csv` (service and event tags per file).
- To add work: tag it in `curation.csv`, run the build script, redeploy.
- WhatsApp number and brand facts live at the top of `site/app.js` (`WA`) and in `site/i18n.js`.
